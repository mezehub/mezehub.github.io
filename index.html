What is Mezehub?

Mezehub is a central source of resources for the MezeLounge (MHF-Z) private server. It contains various guides and resources split across sections for all levels of players. The website sections are as follows:

  • Server Resources - A list of useful server resources, including Achievement Guides, the MezeLounge Server Essentials guide, the Decoration Refinement Guide, the Hiden Armor & Deco Guide, the Raviente Rebalance overview, the UL Zenith Update, the Achievement Roles overview, the Transmog Overview, and the Hunting Road Shop.

    • How do I play on MezeLounge?

  • First, make sure you’ve downloaded our client.
  • Extract the files and open the mhf.exe.
  • Once open, input your desired username and password, and the game will register you automatically.

    • Note: Anti-virus software may cause complications with every file being downloaded, or flagging it as a virus. This is a false-positive and you can safely ignore it. The best practice is to input the MHF file path as an exclusion for your protection software. For additional server details, check out our Server Essentials guide.
